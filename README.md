# 🎙️ Speech Emotion Recognition

A machine learning project that analyzes human speech and predicts the emotion expressed in an audio recording. This project was developed using Python and machine learning/deep learning techniques as part of my **CodeAlpha Internship**.

## 📌 Project Overview

Speech Emotion Recognition (SER) is a technology that identifies emotions from human speech. The system processes an audio file, extracts important audio features, and uses a trained machine learning model to predict the speaker's emotion.

The project provides a simple graphical user interface (GUI) where users can select an audio file and receive the predicted emotion.

## 🎯 Objectives

* Detect emotions from human speech.
* Process and analyze audio signals.
* Extract useful speech features.
* Train a machine learning/deep learning model.
* Provide emotion predictions through a user-friendly GUI.
* Demonstrate a practical application of Artificial Intelligence and Machine Learning.

## 😊 Emotions Recognized

The system can be trained to recognize emotions such as:

* 😄 Happy
* 😢 Sad
* 😠 Angry
* 😐 Neutral
* 😨 Fear
* 🤢 Disgust
* 😲 Surprise

*The exact emotions depend on the dataset and model used.*
